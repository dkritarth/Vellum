- `ask-codex.png`: signed-in Codex response, captured while verifying the markdown rendering fix in PR #213. The answer preserves the paper's conflicting 41.8/41.0 BLEU figures rather than hiding the discrepancy.

- `notes.png`: notes entered through the app beside the paper, captured during panel/restart verification for issue #212 and PR #216.

Captures use isolated application data and contain no personal library or credentials. They show development fixes newer than the v0.1.0 release. Pixel dimensions are recorded in the image files; the website scales images proportionally and links to the originals.
