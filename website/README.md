# Website

GitHub Pages publishes this directory directly, without a build step.

The stylesheet filename contains the first 12 hex digits of its SHA-256 content hash. After editing CSS, rename the file using its new hash and update the link in `index.html`. Changing the URL prevents returning visitors from combining new HTML with a cached older theme.

For local preview, run `npx vite website`. Screenshot provenance is in `assets/screenshots/README.md`.
