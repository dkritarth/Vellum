# Vellum v0.1.1-beta.1

An early beta of the local-first research workspace. MIT license. Apple Silicon Macs running macOS 13 Ventura or later.

## Download and install

Download `Vellum-0.1.1-beta.1-arm64.dmg`, open it, and move Vellum to Applications. A ZIP is also available. `SHA256SUMS.txt` lists the file hashes.

This beta is ad-hoc signed, not Apple-notarized. If macOS blocks first launch, review [Apple's guidance](https://support.apple.com/en-us/102445). If you trust this repository's download, try opening Vellum, then use System Settings > Privacy & Security > Open Anyway. Do not disable Gatekeeper globally.

Install an ACP adapter and sign in before using AI. Codex is the verified subscription path; see [setup](https://github.com/dkritarth/Vellum#quick-start).

## What works in this beta

- Import real papers, use Library search and collections, and read continuous PDF pages with search, zoom, outline, and reference navigation.
- Select text for Add to chat, Explain, or highlights. Ask receives paper and page context through the signed-in Codex adapter.
- Keep notes, highlights, and conversations across app restarts. Restore papers from Trash before reopening their conversations.
- Recover from failed metadata loads and collection writes without losing the visible paper or draft.
- Resize or collapse side panels and inspect authentic usage telemetry.

The [two-part walkthrough and verification report](https://github.com/dkritarth/Vellum/blob/master/docs/verification/daily-workflow-2026-11-16.md) cover 27 passing chapters in the actual Electron app.

The beta also updates Electron to 45.3.3, PDF.js to 6.2.108, and transitive Zod to 4.6.7 after a dependency security audit. SQLite 13.2.0 provides compatible N-API bindings for the updated runtime. The original walkthrough predates these dependency updates; release verification separately checks the updated runtime.

The [updated-runtime verification](https://github.com/dkritarth/Vellum/blob/master/docs/verification/beta-runtime-2026-11-16.md) repeats all 27 chapters with signed-in Codex and restart persistence.

## Limits

This is a beta. Keep backups of important research files. The core workflow and signed-in Codex answers were exercised on Linux. The Mac workflow builds the arm64 package and checks its native SQLite binding, signature, and packaged boot/reader/persistence smoke. Physical Mac trackpad behavior and a signed-in Mac AI session were not manually certified.

Claude remains supported but exploratory testing encountered a provider rate limit. Gemini application answers were not certified. Workspaces and slash/context pickers remain coming-soon features. No Intel Mac build is provided for this release.

## Updating

Install a newer beta over the existing application. App updates do not include or replace your local paper library. There is no automatic updater yet. Check the [release list](https://github.com/dkritarth/Vellum/releases) for occasional updates and release-specific notes.
